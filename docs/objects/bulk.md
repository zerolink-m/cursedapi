# Bulk object

Результат частично выполненной bulk-операции. Содержится в [Data object](data.md) под ключом имени объекта во множественном числе.

## Схема

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| succeeded | array | Да | Объекты, над которыми операция прошла успешно |
| failed | array | Да | Объекты, над которыми операция не прошла |

Элемент `failed`:

| Поле | Тип | Описание |
|------|-----|----------|
| id | any | Идентификатор объекта (если удалось определить) |
| error | [Error object](error.md) | Причина неудачи |

## Пример

```json
"users": {
    "succeeded": [
        { "id": 1, "name": "ok_user" }
    ],
    "failed": [
        {
            "id": 2,
            "error": {
                "error": "Validation error: field 'name' is required",
                "fields": {
                    "name": {
                        "error": "is required",
                        "required": true,
                        "type": "string"
                    }
                }
            }
        }
    ]
}
```

## Правила

1. Bulk object используется только с кодами `002`/`004`/`008` (partially). При полном успехе - обычный массив объектов.
2. `succeeded` и `failed` присутствуют всегда, даже если один из них пуст.
3. Если операция не прошла ни для одного объекта - код не `002`, а соответствующая ошибка (например `109`), и bulk-обёртка не используется.
4. Порядок элементов соответствует порядку идентификаторов в запросе.
