# Data object

Полезная нагрузка. Содержится в [Envelope object](envelope.md) -> `data` (ответ) и в [Request object](request.md) -> `data` (запрос). Структура зеркальна в обе стороны.

Структура зависит от типа операции:

| Операция | Ключ в `data` | Содержимое |
|----------|---------------|------------|
| Список (массовая отдача) | `settings` + имя объекта во множественном числе | [Settings object](settings.md) + массив объектов |
| Одинарная (get/patch/post/delete) | имя объекта в единственном числе | объект или `null` |
| Bulk GET (массовое получение по `/bulk/{ids}`) | `settings` + имя объекта во множественном числе | [Settings object](settings.md) + массив объектов |
| Bulk частично | имя объекта во множественном числе | [Bulk object](bulk.md) |
| Bulk полностью | имя объекта во множественном числе | массив объектов |
| Virtual-эндпоинт | любое | любое (см. [paths.md](../paths.md), раздел Virtual-объект) |

Bulk GET возвращает `settings` как обычный список: `total` равен числу
запрошенных идентификаторов, `limit`/`offset` не применяются. Код успеха - тот
же, что у обычного списка (`000`).

В запросе ([Request object](request.md)) используются те же ключи, кроме `settings`: одинарная - единственное число, bulk - множественное с массивом объектов. Списки (GET) телом не принимаются.

## Список

```json
"data": {
    "settings": { "...": "Settings object" },
    "users": [
        { "id": 1, "name": "user_name", "added_at": 123456789 }
    ]
}
```

## Одинарная

```json
"data": {
    "user": {
        "id": 1,
        "name": "user_name",
        "added_at": 123456789
    }
}
```

## Bulk (частично)

```json
"data": {
    "users": {
        "succeeded": [ { "id": 1, "name": "ok_user" } ],
        "failed": [ { "id": 2, "error": { "...": "Error object" } } ]
    }
}
```

## Правила

1. Имя ключа объекта - snake_case, во множественном числе для списков и bulk, в единственном для одинарных.
2. При `code` `012` (Empty result) - массив пустой `[]`, но присутствует.
3. При удалении (`007`) `data` может содержать удалённый объект или `{}`.
4. Связанные объекты раскрываются по query-параметру `expand` - см. [query.md](../query.md).
