# Options object

Опции выполнения операции. Содержится в [Request object](request.md) -> `options`. Опционален.

## Схема

Встроенные опции:

| Поле | Тип | Default | Описание |
|------|-----|---------|----------|
| partial_allowed | bool | false | Разрешить частичное выполнение bulk-операций. Без него bulk атомарен |

Кастомные опции: любой сервис может добавлять в `options` свои поля - схема открыта для расширений.

## Пример

```json
{
    "options": {
        "partial_allowed": true,
        "notify": false,
        "dry_run": true
    }
}
```

## Правила

1. `options` не является частью данных - только управляющие флаги.
2. Значение опции из `options` **перекрывает** одноимённый query-параметр (например `partial_allowed`).
3. Неизвестные опции сервер игнорирует (прямая и обратная совместимость сервисов).
4. Кастомные опции рекомендуются в snake_case.
